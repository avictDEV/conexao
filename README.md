# 📚 Conexão Biblioteca

Sistema desenvolvido para gerenciamento de biblioteca, com foco em organização de livros, usuários e controle de empréstimos.

O projeto foi criado com objetivo de praticar desenvolvimento web, organização de sistemas e lógica de programação utilizando tecnologias voltadas para aplicações PHP.

---

## 🚀 Funcionalidades

- Cadastro de livros
- Cadastro de usuários
- Controle de empréstimos
- Organização de acervo
- Estruturação de dados
- Interface para gerenciamento básico

---

## 🛠 Tecnologias Utilizadas

- PHP
- HTML5
- CSS3
- MySQL
- XAMPP
- SQL
- Programação Orientada a Objetos (POO)
